# Multi-Tenant Data Storage Module

## Overview
Bộ tài liệu thiết kế kiến trúc cho Module Lưu trữ Multi-Tenant. Module này cung cấp giải pháp lưu trữ linh hoạt (Flexible Data Engine), quản lý dữ liệu tĩnh và động (JSONB) với cơ chế cô lập dữ liệu (Schema-per-Tenant) và hệ thống Rule Engine điều khiển bởi Metadata.
